# Versioning and release management

**Status:** Not yet formally defined.

Breeze On does not currently maintain organization-wide versioning or release-management standards.

## Scope of future standards

When conventions are established, this document may cover areas such as:

- Package versioning
- Release processes
- Tagging conventions
- Compatibility expectations

## Current practice

Until organization-wide standards exist, repositories may version and release packages according to their own practices. NuGet and other package versions in use today reflect those practices, not a documented org strategy.

## For contributors

When versioning and release conventions become agreed and implemented across the organization, update this document to describe **current reality only**. Do not define a versioning strategy ahead of adoption.
