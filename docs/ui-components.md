# UI component standards

Shared UI conventions for Breeze On applications.

## Current state

No organization-wide shared component library package is published yet.

Application UIs (e.g. ADM) use in-repo Blazor components and layout (navigation, cards, pages) consistent with that product’s shell.

## When shared components are introduced

Document each shared component here (name, purpose, repo/package, usage expectations) at the time it exists — including any shared Drop-Down List (DDL) control — and keep this file current-state only.
