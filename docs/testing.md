# Testing

Owner: Documentation

**Status:** Not yet formally defined.

Breeze On does not currently maintain organization-wide testing standards.

## Scope of future standards

When conventions are established, this document may cover areas such as:

- Unit testing
- Integration testing
- Smoke testing
- Naming conventions
- Coverage expectations

## Current practice

Until organization-wide standards exist, repositories may implement testing approaches independently. Local test scripts and CI checks in a given repo are that repo’s practice, not org standards, unless documented here.

## For contributors

When testing conventions become agreed and implemented across the organization, update this document to describe **current reality only**. Do not invent testing requirements ahead of adoption.
