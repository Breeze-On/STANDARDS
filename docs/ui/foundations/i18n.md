# UI — Localization (culture + timezone + resources)

Owner: UI

Current reality for language / timezone preferences and per-application UI string resources. Related: [shell.md](../shell/shell.md) (Settings), [forms.md](../controls/forms.md) (`BoDropDownList`), [overview.md](../overview.md).

## Per-application resource library (locked — hard standard)

1. **Each application owns its own resource library** (`.resx` + culture satellites). Examples: SHARED-UI Gallery uses `BoUi` in `BreezeOn.UI`; EAC uses **`EacResources`** in `SYSTEM-ADMIN-EAC` (`EacResources.resx` / `EacResources.fr.resx` via `IEacLocalizer`) — it must **not** reuse Gallery/`BoUi` keys as a shared glossary.
2. **Never hardcode user-visible labels** in Razor/C# (page titles, nav labels, tab/section/field labels, buttons, dialog copy, aria-labels meant for users, etc.). Always resolve through a Resource key via a locale-aware localizer.
3. **Do not share string catalogs across applications** for the same conceptual word. Even common words such as “Close” must live in **that app’s** resources so each product/company can choose its own wording.
4. `BreezeOn.UI`’s `BoUi.resx` / `BoUi.fr.resx` are the resource library for the **SHARED-UI Gallery host** (and chrome it demos). They are **not** an org-wide translation pack for other apps.

## Preferences (locked)

| Concern | Standard |
| --- | --- |
| Service | `IBoLocaleService` (scoped); restore via `BoLocaleBootstrap` inside `BoProviders` |
| Language options | `en` (English), `fr` (Français) — fixed catalog |
| Timezone options | Curated IANA list (Canada-first + UTC + common peers); default `America/Toronto` |
| Apply behavior | Settings DDLs update the service **immediately** (no separate Save); Close only dismisses |
| Formatting culture | `IBoLocaleService.FormatCulture` — `en` → `en-CA`, `fr` → `fr-CA` (numbers, dates, grid pager) |
| UI resource culture | `IBoLocaleService.UiCulture` — `en` / `fr` primary tags for resource lookup (`IBoUiLocalizer` reads this, not ambient culture) |
| Process-wide culture | **Not mutated.** `BoLocaleService` does **not** set `CultureInfo.DefaultThreadCurrentCulture` / `DefaultThreadCurrentUICulture`; culture is per circuit via the service |
| Formatting rule | Prefer **`Locale.FormatCulture`** over ambient `CultureInfo.CurrentCulture` when formatting in components or host pages. `BoNumberField` / `BoDateField` and `BoGrid` (including the pagination “Showing … of …” text) use `FormatCulture` |
| Date / datetime **display** | User-facing date and datetime text always uses the user’s format culture **and** (for UTC instants) their selected timezone. Use SHARED-UI **`BoDateDisplay`**: `Format` for wall-clock / `BoDateField` values; **`FormatUtc`** for stored UTC instants (`*Utc` columns, sync/login timestamps, audit times). Do **not** show raw UTC/`"u"` / invariant strings in grids or read-only fields. `Unspecified` Kind from SQL is treated as UTC by `FormatUtc`. |

### Cookie contract

| Cookie | Values | Default if missing/invalid |
| --- | --- | --- |
| `bo-culture` | `en` \| `fr` (lowercase) | `en` |
| `bo-timezone` | IANA id (e.g. `America/Toronto`) | `America/Toronto` |

Shared attributes (same family as `bo-theme-mode`): `Path=/`; `Max-Age≈31536000` (1 year); `SameSite=Lax`; `Secure` when HTTPS; `HttpOnly=false` (JS-readable for Interactive Server). Hosts load `_content/BreezeOn.UI/js/bo-locale.js` early (gallery `App.razor`).

## Resource foundation (SHARED-UI / Gallery — current)

- Library resources: `Resources/BoUi.resx` (default English) + `Resources/BoUi.fr.resx` (satellite `fr`)
- Resolve strings via **`IBoUiLocalizer`**, which reads `IBoLocaleService.Culture` explicitly so language switches apply **immediately without a full page reload** (ambient `IStringLocalizer` / request culture alone is not enough on Interactive Server)
- Marker type: `BreezeOn.UI.Resources.BoUi`
- **Shipped:** Gallery + shell chrome user-visible strings (nav, header tabs, Theme/Components/Home, Settings, Profile Sign out, dialogs, toasts, page freeze, aria labels, etc.). Shell aria/title strings use `Chrome_Aria_*` keys (nav, collapse/expand, validation-failed badge, page freeze) — see [navigation.md](../shell/navigation.md). Page freeze default message is `PageFreeze_PleaseWait`; apps pass already-localized operation messages into `IBoPageFreezeService` — [overlays.md](../shell/overlays.md).
- Layouts/pages that show localized text should subscribe to `IBoLocaleService.Changed` and re-render

### Host requirements

1. `AddBreezeOnUI()` (registers locale + `IBoUiLocalizer`)
2. Configure supported cultures `en` / `fr` (`RequestLocalizationOptions`) and `UseRequestLocalization()`
3. Render `BoProviders` (locale bootstrap) and load `bo-locale.js` early (full asset list: [page-development.md § Host integration](../page-development.md#host-integration-required))

## Settings composition (locked)

Dialog has **no** popup header title or × button. Content:

1. One `BoSectionMain` titled **Settings** (localized)
2. `BoRow` → `BoDropDownList` Language (`FieldKey=Language`)
3. `BoRow` → `BoDropDownList` Timezone (`FieldKey=Timezone`)
4. Footer Close button (and backdrop click) dismisses

## Resource foundation (EAC — current)

- Host resources: `src/BreezeOn.Eac/Resources/EacResources.resx` (default English) + `EacResources.fr.resx` (satellite `fr`)
- Resolve strings via **`IEacLocalizer`**, which reads `IBoLocaleService.Culture` explicitly (same immediate-switch pattern as Gallery)
- Marker type: `BreezeOn.Eac.Resources.EacResources`
- **Shipped:** shell brand, nav labels, Home hub cards, per-page `AppTitle` / `Subtitle`, page titles, blazor-error UI strings
- Layouts/pages that show localized text subscribe to `IBoLocaleService.Changed` and re-render

## EAC domain translations (data — current)

EAC Application Configuration → **Translations** manages **EAC-owned data translations** (not UI `.resx`):

- Enabled languages are per **Application Context** (`EACApplicationsEnabledLanguages`); default `en-CA` is authoritative and locked.
- Catalog covers Data Entity row Description, Process Framework column labels + TEXT metadata, and Variable TEXT values.
- Status is calculated (`Matched` / `Unmatched`); absent or stale non-default values are Unmatched.
- Bulk maintenance is **Excel-only** (wide language columns). See [data-portability.md](../../data-portability.md) § Translations Excel.
- Business-application string catalogs remain owned by their product repositories (out of EAC scope).

## Explicit non-goals (not current reality)

- Per-user DB preference store
- Localizing framework reconnect modal static HTML (gallery host template)

Profile photos are stored in `Identity.UserPhotos` (login-time Graph refresh; platform Identity). `BoProfileMenu` may still show initials until product hosts bind the SHARED-UI photo helper. Sign-out is wired through SHARED-UI Account endpoints.
