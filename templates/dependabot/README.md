# Dependabot template

Owner: Engineering

Baseline: [`dependabot.yml`](dependabot.yml) — weekly `nuget` + `github-actions` updates.

**Templates are baselines.** Product repositories **may extend** this file when justified (for example Dependabot `ignore` rules, supply-chain exceptions, or other product-specific policy). Extensions must remain greppable (owner + reason comments).

When refreshing a product `.github/dependabot.yml` from this template: **merge**, do not blindly overwrite — do not remove documented product extensions without owner review.

Policy SSOT: [`docs/security-governance.md`](../../docs/security-governance.md).
